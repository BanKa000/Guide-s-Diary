# Дневник проводника

Сюжетный мод для S.T.A.L.K.E.R.: Зов Припяти (Затон → Юпитер). Версия для **IX-Ray (ixray-1.6-stcop)**.
Герой — Лазарь, главный заказчик — Борода. В игре: блокнот и КПК-дневник, цепочка основных заданий, долги Компаса,
побочные задания Бороды и других NPC.

> Статус: тестовая сборка. После последних правок игра автором не запускалась, проверялся только синтаксис скриптов.

## Структура репозитория
| Папка | Что внутри |
|---|---|
| `gamedata/` | **сам мод**: файлы, которые мод добавляет или меняет в `gamedata` IX-Ray (366 файлов). Структура папок как в игре |
| `dev-tools/` | инструменты разработчика (телепорт, запись точек, переход по стадиям) — не для релиза |
| `src/` | исходники: скрипты, конфиги, тексты, `gen/` и `tools/diary_build.py` (генератор диалогов, персонажей, заданий) |

## Установка (для тестеров)
1. Нужен IX-Ray (ixray-1.6-stcop) с аддонами в `ixr_addons`: `ixray-pattern-recoil-stcop`, `ixray-stcop-wp-3.8-based`,
   `ixray-stcop-wp-3.8-cop`, `ixray-stcop-wp-outfits`, `lxrd-loadout-stcop`.
2. Скопируйте папку `gamedata` из репозитория в корень игры (рядом с `bin` и `ixr_addons`), объединив папки с заменой файлов.
   Предварительно сделайте копию своей `gamedata`.
3. Начните новую игру: старые сохранения не подходят.

Подробности и что присылать при вылете — в `УСТАНОВКА.txt`.

В репозитории только файлы мода. Остальные файлы `gamedata` (шейдеры, шрифты, базовые конфиги IX-Ray) не менялись и берутся из установленной игры.

## Сборка из исходников
`src/tools/diary_build.py` берёт исходные файлы игры (`character_desc_*`, `dialogs`, `tm_zaton` и др.), добавляет к ним
содержимое `src/` и пишет результат в `gamedata`. Оригинальные файлы игры в репозиторий не входят.

## Известные проблемы
- Вылет движка `shared_motions::motion_def` при игре с оружием из аддона (в дампе `wpn_rpk_hud`, `anm_reload_nosco`); причина не подтверждена.
- Не проверено в игре: сцена с бандитами («Ложный SOS»), разговор с должником Компаса.
